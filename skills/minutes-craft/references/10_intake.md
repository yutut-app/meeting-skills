# 素材の読み方

**素材の種別で読み方が変わる。** 種別を先に判定してから読む。
判定を飛ばすと、文字起こしに対してメモ用の読み方を当てて、発言者が混ざる。

| 種別 | 見分け方 | 主な仕事 |
|---|---|---|
| 文字起こし | 話者ラベルがある、同じ内容が言い直されている、口語 | **重複と言い直しの整理**。情報は足りているので削る方向 |
| 手書きメモ | 箇条書きの断片、主語が無い、矢印や記号 | **欠けている情報の特定**。情報が足りないので問う方向 |
| 両方が混在 | 文字起こしに手書きの補足が付いている | 文字起こしを土台にし、メモは**補足として区別して扱う** |

---

## 1. 文字起こしを読むとき

### 削ってよいもの

- 言い直し（「えー」「あの」、同じ文の繰り返し）
- 挨拶、世間話、休憩のやりとり
- **同じ結論に至る複数の発言のうち、結論を含まない途中の発言**

### 削ってはいけないもの

| 残すもの | なぜ |
|---|---|
| **条件や留保の言葉**（「基本的には」「持ち帰って」「仮に」） | **ここが合意と未決を分ける。**消すと条件付き合意が合意に見える |
| 相手が明示した期限・数量・金額 | 後から突き合わせる対象そのもの |
| **言った人** | 誰の発言かで重みが変わる。相手先の担当者と決裁者は同じではない |
| 自社に不利な発言 | 役割の規約どおり、丸めない |

### 話者ラベルが無い・崩れているとき

**推測で割り当てない。** 「話者A」のまま残し、誰かを確定できないことを
基本情報の確認（手順1）で一緒に問う。

**自動文字起こしは語を誤変換する。** 会社名・人名・型番のほか、
**その分野の専門用語**が崩れる。読める語に化けるため、気づかないまま相手に渡る。

**崩れた語は `15_terms.md` の工程に回す。** 洗い出し、分野を調べ、
候補を出して合否を問う。**そのまま載せて終わりにしない。**

**勝手に直さないことは変わらない。** 外すのは「調べない」「聞かない」の2つだけで、
原本を書き換えないことと、推測で1つに確定しないことは**同じく効く**。

---

## 2. 手書きメモを読むとき

**メモは「決まったこと」だけが書かれ、「なぜ」と「誰が」が落ちていることが多い。**
書き手は覚えているつもりで書くため、落ちたことに気づいていない。

### 落ちやすい4つ

| 落ちるもの | 問い方 |
|---|---|
| **担当** | 「<項目>は、どちらが持つことになりましたか（自社／相手先／未定）」 |
| **期限** | 「<項目>の期限は決まりましたか。決まっていなければ未決として残します」 |
| **決定の理由** | 「<項目>を<結論>にしたのは、どういう理由でしたか」 |
| **相手の反応** | 「<自社の提案>に対して、相手先は合意しましたか、持ち帰りでしたか」 |

**4つすべてを毎回聞かない。** 本文を書いてみて、空いた箇所だけを問う。
全部先に聞くと、メモに書いてある分まで聞くことになり、利用者の手間が増える。

### 略記は、何の略かを確かめる

手書きメモの「全検」「変化点」「ヨコ展」のような略記は、**略記そのものは正しいが、
何の略かが相手と違うことがある。** `15_terms.md` の型5で候補に挙げ、合否を問う。

### 矢印と記号を解釈しない

`A → B` は「A の次に B」「A だから B」「A を B に変更」のどれでもありうる。
**どれか1つに決めない。** 本文では「要確認」を付け、素材の表記を併記する。

実際に起きる誤りは、矢印を「変更」と読んで**変更前の値を落とすこと。**
落ちたことは出力に現れないため、利用者が原本を見るまで分からない。

---

## 3. 両方が混在するとき

文字起こしを土台にする。**メモを土台にしない。**
メモは書き手の解釈が入っているため、土台にすると解釈が事実として固定される。

| メモの内容 | 扱い |
|---|---|
| 文字起こしにも同じ内容がある | 文字起こしを採る。一致しているので問題にしない |
| 文字起こしに無く、メモにだけある | **「メモより」と出所を付けて残す。**区分は「要確認」 |
| **文字起こしと食い違う** | **両方を併記し、区分を「要確認」にする。**どちらかを選ばない |

**食い違いを黙って解消しない。** 食い違いそのものが、確認すべき事実。
片方を採って静かに通すと、なぜその値になったのかが後から追えない。

---

## 4. 素材を読み終えたら出すもの

本文（手順3）に進む前に、次の表を出す。**読んだ範囲を示すため。**

| 項目 | 内容 |
|---|---|
| 素材の種別 | 文字起こし／手書きメモ／混在 |
| 読んだ量 | 行数または文字数。**一部しか読んでいないならそう書く** |
| 読み取れた基本情報 | 日付・相手先・出席者と、それぞれの出所 |
| 読み取れなかったもの | 必須のうち欠けているもの（これが埋まるまで本文を書かない） |
| 判然としなかった箇所 | 件数と、その場所。手順1の承認で一緒に問う |

**「判然としなかった箇所: 0件」と書けるのは、本当に無いときだけ。**
0件が続くなら、探していない疑いがある。素材に曖昧さが無いことは稀。
