# meeting-skills

会議の記録に関するスキルを置くリポジトリ。**公開している。**

## 入っているスキル

| スキル | 役割 |
|---|---|
| [minutes-craft](skills/minutes-craft/) | 顧客・仕入先との打合せの文字起こし・メモから議事録を作る |

## 置いてよいもの、置いてはいけないもの

| 置く | 置かない |
|---|---|
| スキル本体、雛形、判断の規約 | **議事録の実物、文字起こし、取引先名を含むメモ** |
| 原因の台帳（`docs/feedback.md`） | 取引先ごとの書式の癖・呼称の決めごと |
| 壊れた入力の記録（取引先名を伏せたもの） | 個人名、単価、不良の内容 |

**一度 push したものは履歴から取り除けない。** 議事録の実物は
`scripts/ws-path.sh` が返す作業スペースに置く。

## スキルの登録

```bash
ln -s "$(pwd)/skills/minutes-craft" ~/.claude/skills/minutes-craft
```

## 改訂

`skill-builder` スキルを使う。このリポジトリのスキルを直接書き換えない。
